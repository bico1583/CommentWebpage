# Comments Page

Frontend coding assignment implementing a threaded comments page using vanilla HTML, CSS and JavaScript.

## Features

- User registration and login
- Session-based authentication
- Threaded comments and replies
- Comment nesting
- Comment moderation
- Configurable inappropriate-word list
- LocalStorage for users and comments

## Running the project

The project should be served through a local web server because the moderation Web Worker loads the word list from a JSON file.

## Technologies

- HTML
- CSS
- JavaScript
- Web Workers
- LocalStorage
- SessionStorage
